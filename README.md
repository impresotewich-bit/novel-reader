# Meaw Meaw Read

ชั้นหนังสือธีมลูกแมวสามสี อ่าน PDF เป็นข้อความ ปรับขนาดตัวอักษรได้ มีโหมดสว่าง มืด ถนอมสายตา และกลางคืน

## แปลงหนังสือสแกน (บน Mac, ฟรี, ไม่ใช้ claude.ai)

```bash
./novel scan                 # แปลงทุก PDF ในโฟลเดอร์ "สแกน"
./novel scan เล่มหนึ่ง.pdf     # หรือระบุไฟล์
./novel list                 # ดูหนังสือบนชั้น
./novel remove "ชื่อเรื่อง"    # เอาเล่มออกจากชั้น
./novel push                 # ส่งการเปลี่ยนแปลงขึ้น GitHub
./novel password             # เปลี่ยนรหัสเข้าเว็บ
./novel open                 # เปิดเว็บชั้นหนังสือ
```

เว็บต้องใส่รหัสก่อนเข้า หนังสือที่อ่านได้อยู่ใน `library/` บนเครื่องเท่านั้น ส่วนที่ขึ้น GitHub (`books/`) เป็นไฟล์
เข้ารหัส AES-256-GCM ด้วยกุญแจที่ได้จากรหัสเว็บ (PBKDF2-SHA256) — ไม่มีรหัสก็อ่านไม่ได้ แม้ repo จะเป็นสาธารณะ
รหัสเก็บใน Keychain ของ Mac ไม่อยู่ใน repo

ใช้ Apple Vision แปลงภาพเป็นข้อความบนเครื่อง แล้วเข้ารหัสลง `books/` และ commit + push ขึ้น GitHub อัตโนมัติ
(ตั้ง `NOVEL_NO_PUSH=1` เพื่อปิด) ไฟล์ PDF ต้นฉบับไม่ขึ้น GitHub

หรือดับเบิลคลิก `แปลงสแกน.command`

## ไฟล์

- `index.html` — หน้าใส่รหัส ชั้นหนังสือ และหน้าอ่าน
- `library/` — หนังสือที่แปลงแล้ว (อ่านได้, ไม่ขึ้น GitHub)
- `books/` — สำเนาเข้ารหัสสำหรับเว็บ
- `tools/vault.json` — ค่า salt สำหรับรหัสเว็บ (ไม่ใช่ตัวรหัส)
- `tools/thai-ocr.swift` — ตัวแปลง PDF → ข้อความ
- `assets/` — ภาพลูกแมว
