# ห้องอ่านหนังสือ

ชั้นหนังสือธีมลูกแมวสามสี อ่าน PDF เป็นข้อความ ปรับขนาดตัวอักษรได้ มีโหมดสว่าง มืด ถนอมสายตา และกลางคืน

## แปลงหนังสือสแกน (บน Mac, ฟรี, ไม่ใช้ claude.ai)

```bash
./novel scan                 # แปลงทุก PDF ในโฟลเดอร์ "สแกน"
./novel scan เล่มหนึ่ง.pdf     # หรือระบุไฟล์
./novel list                 # ดูหนังสือบนชั้น
./novel remove "ชื่อเรื่อง"    # เอาเล่มออกจากชั้น
./novel push                 # ส่งการเปลี่ยนแปลงขึ้น GitHub
./novel open                 # เปิดเว็บชั้นหนังสือ
```

ใช้ Apple Vision แปลงภาพเป็นข้อความบนเครื่อง ผลลัพธ์อยู่ใน `books/` และถูก commit + push ขึ้น GitHub อัตโนมัติ
(ตั้ง `NOVEL_NO_PUSH=1` เพื่อปิด) ไฟล์ PDF ต้นฉบับไม่ขึ้น GitHub

หรือดับเบิลคลิก `แปลงสแกน.command`

## ไฟล์

- `index.html` — หน้าเว็บชั้นหนังสือและหน้าอ่าน (โหลดหนังสือจาก `books/index.json` เมื่อเปิดผ่านเว็บ)
- `books/` — หนังสือที่แปลงแล้ว (`.book.json`) และภาพปก
- `tools/thai-ocr.swift` — ตัวแปลง PDF → ข้อความ
- `assets/` — ภาพลูกแมว
