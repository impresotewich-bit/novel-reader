วางไฟล์ PDF ตรงนี้เพื่อเพิ่มเข้าชั้นหนังสือ

เล่มนี้เป็นภาพสแกน

  1. แปลงในเครื่องนี้ (ฟรี ใช้ได้ทุกอุปกรณ์): หน้าละ 1–3 วินาที ครั้งแรกต้องโหลดตัวอ่านภาษาไทยราว 13 MB ระหว่างแปลงอ่านหน้าที่เสร็จแล้วไปก่อนได้
  2. ให้ Claude อ่าน: แม่นที่สุดสำหรับสแกนไม่ชัด แต่ช้ากว่าและใช้โควตา Claude ของคุณ
  3. บน Mac: ./novel scan ใช้ Apple Vision แม่นและเร็ว เหมาะกับเล่มหนา

ชั้นออนไลน์

ทุกอุปกรณ์ที่ใส่รหัสเว็บใช้ชั้นหนังสือเดียวกันแล้ว เพิ่ม ลบ และตำแหน่งที่อ่านค้างไว้จะตรงกันทุกเครื่อง

ยังไม่มีกุญแจร่วม ให้รัน ./novel token บน Mac ครั้งเดียว ทุกอุปกรณ์จะใช้ชั้นเดียวกันทันที หรือจะเชื่อมเฉพาะอุปกรณ์นี้ก็ได้:

  1. เปิด สร้างกุญแจบน GitHub (Fine-grained token)
  2. Repository access เลือก Only select repositories → repo ของเว็บนี้
  3. Permissions → Repository → Contents: Read and write แล้วกด Generate
  4. คัดลอกกุญแจมาวางด้านล่าง
